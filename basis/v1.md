# The basis record, version 1

Predicate type: `https://securomatic.dev/basis/v1`

Securomatic writes an OpenVEX document for each release of a product
it assesses, naming the release's image by digest. Beside it, it writes
a **basis record**: what the document rests on, signed by Securomatic,
so the product can check where a document came from before attesting
it to its images with its own identity.

Securomatic keeps the reasoning behind each verdict (the product model,
its facts, and the rules) private. The basis record commits to exactly
what was used, by hash, without revealing it: anyone later given those
files can check them against the record.

## The statement

An [in-toto Statement v1](https://github.com/in-toto/attestation/blob/main/spec/v1/statement.md):

- **`subject`**: the VEX document (named `vex.openvex.json`, by the
  sha256 of its bytes as written), and the image it names (by its
  repository and digest).
- **`predicateType`**: the URI above.
- **`predicate`**:

| Field | What it says |
|---|---|
| `product` | `id`, `name` and `vendor` |
| `release` | `version`, `git_tag` (or null), `commit` (the full SHA the image was built from), `built_at` (or null) |
| `image` | `repo`, `platform` (`linux/arm64`) and `digest` (`sha256:...`) |
| `sbom` | `sha256` of the release's SBOM document (decompressed), or null |
| `scan` | `scanner` (`grype`), its `version`, `db_built` (its vulnerability database's build time), `scanned_at` |
| `vex` | the document's `id` and `version` |
| `product_model` | its `version`, and `sha256` of the model (with its facts) as Securomatic loads it |
| `rules` | each rule that applied: its `id`, `sha256` as Securomatic loads it, and `method`, the version of Securomatic's assessment method (which holds the threat model) it was made with, or null for a rule made by hand |
| `securomatic` | Securomatic's `version` |
| `made_at` | when the record was made |

Times are UTC, as `2026-11-21T12:00:00Z`. Fields may be added within
version 1; a change to what a field means is a new version.

A record is made again when anything in it changes other than
`made_at`: a new VEX version, and also each new scan, so a release's
latest record says when it was last re-checked.

## The signature

The statement's JSON is signed as a
[DSSE](https://github.com/secure-systems-lab/dsse) envelope, payload
type `application/vnd.in-toto+json`, with ECDSA P-256 and SHA-256 over
DSSE's pre-authentication encoding, and saved as a
[Sigstore bundle](https://docs.sigstore.dev/about/bundle/) (v0.3,
`basis.sigstore.json`). The bundle's `verificationMaterial.publicKey.hint`
is the signing key's id (see [keys/](../keys/)). Records aren't
written to a transparency log yet.

## Verifying one

With jq, openssl and the public key, in the directory with
`basis.sigstore.json` and `vex.openvex.json`:

```sh
set -e
B=basis.sigstore.json
T=$(jq -r .dsseEnvelope.payloadType "$B")
test "$T" = application/vnd.in-toto+json
jq -r .dsseEnvelope.payload "$B" | base64 -d > payload.json
jq -r '.dsseEnvelope.signatures[0].sig' "$B" | base64 -d > sig.der
# What DSSE signs: "DSSEv1 <len(type)> <type> <len(payload)> <payload>"
{ printf 'DSSEv1 %d %s %d ' "${#T}" "$T" "$(wc -c < payload.json | tr -d ' ')"
  cat payload.json; } > pae.bin
openssl dgst -sha256 -verify securomatic.pub -signature sig.der pae.bin
test "$(jq -r .predicateType payload.json)" = \
  https://securomatic.dev/basis/v1
want=$(jq -r '.subject[] | select(.name == "vex.openvex.json") | .digest.sha256' payload.json)
test "$want" = "$(shasum -a 256 vex.openvex.json | cut -d' ' -f1)"
```

Then, before attesting the VEX document, a product should also check
that it built the image the record names, from the record's commit (its
own build attestation for that digest), and read Securomatic's public
key from a branch Securomatic can't write to.

## Earlier records

Until November 2026, when Securomatic was called autosec, records had
the predicate type `https://github.com/dave-finlay/autosec-public/blob/main/basis/v1.md`
and an `autosec` field where they now have `securomatic`; they are
otherwise the same.
